Перша стабільна версія «Нитки», зафіксована 14 жовтня 2026 року. До цієї точки завжди можна повернутися.

**Сайт:** https://nytka.life (версія сервіс-воркера `nytka-75815bdaab`)

### Що входить

**Сайт і спільна основа застосунку**
- 192 цінності українською та англійською: пояснення, приклад із життя, питання до себе
- Сортування «Моє / Можливо / Ні», «Топ-5», оцінки «Наскільки це важливо» і «Наскільки я цим живу зараз», нотатки
- «Мої цінності»: порівняння «важливо ↔ як живу», підсумок для психотерапевта
- Екран «Про проєкт», на широкому екрані — полотно з вишивкою
- Резервна копія кодом: «Згенерувати код» → «Скопіювати код», «Відновити з коду» з перевіркою вставленого коду. Коди стиснуті (`NYTKA2`), старі коди `NYTKA1` теж приймаються
- Політика конфіденційності та підтримка з кнопкою «На головну»
- Поля вводу без автоматичного наближення на iPhone

**Застосунок (Android та iOS)**
- Свайпи й вібрація, нагадування, блокування Face ID / відбитком / PIN
- PDF для терапевта, резервна копія у файл, щомісячна переоцінка з графіком
- Щоденник кроків, підготовка до сесії, віджет

### Файли
- `nytka-1.0.0-android-test.apk` — тестова (debug) збірка Android саме цієї версії. Для встановлення на телефон, не для Google Play.

### Перевірка
- Сайт розгорнуто на Cloudflare, Android зібрано успішно.
- iOS: для цього коміту збірка не стартувала, бо в GitHub не було вільних macOS-серверів. Остання успішна iOS-збірка — `4402cfa`; зміни після неї не стосуються нативної частини iOS.
