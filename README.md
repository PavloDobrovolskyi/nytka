# Нитка

Веб-застосунок для пошуку особистих цінностей: 192 цінності українською та англійською, сортування «Моє / Можливо / Ні», картки з поясненнями, нотатки, топ-12 → топ-5 і підсумок для терапевта. Усі дані зберігаються тільки в браузері користувача.

## Структура

```
src/
  index.html                      шаблон сторінки: розмітка і стилі
  app.js                          інтерфейс і логіка
  sw.js                           офлайн-режим (версію підставляє build.js)
  content/
    uk-values.js                  166 цінностей українською, згруповані за темами
    uk-values-red.js              ще 26 цінностей
    uk-shadow-and-steps.js        «коли її забагато» і «маленький крок»
    en-1.js, en-2.js, en-3.js     англійські тексти
public/                           шрифти, іконки, manifest — копіюються як є
build.js                          збирає все в dist/
```

## Збірка

```
node build.js
```

Результат з'являється в `dist/`. Зовнішніх залежностей немає.

## Публікація (Cloudflare Pages)

Налаштування проєкту:

- Framework preset: немає
- Build command: `node build.js`
- Build output directory: `dist`

Кожен push у гілку `main` автоматично публікує нову версію.

## Стабільні версії

Стабільні версії позначені на GitHub тегами `vX.Y.Z` і релізами з позначкою «Latest» (там же APK для Android).
Гілка `stable` завжди вказує на останню стабільну версію.

Щоб зафіксувати нову стабільну версію:

1. у `main` оновити `release/VERSION` (наприклад `1.1.0`) і опис у `release/notes.md`;
2. відправити `main` у гілку `stable`: `git push origin main:stable`.

Дія «Stable release» сама поставить тег, збере APK і створить реліз. Повернути сайт до стабільної версії: Cloudflare → Workers & Pages → nytka → Deployments → потрібне розгортання → «Rollback», або `git revert` до тегу.

## Як змінити текст цінності

Українські тексти лежать у `src/content/uk-values.js` і `uk-values-red.js` (поля: `m` — що це, `l` — у житті, `q` — питання, `d` — не плутати, `t` — точніший переклад). «Коли її забагато» і «маленький крок» лежать у `uk-shadow-and-steps.js`. Англійські відповідники знаходяться в `en-*.js` під тим самим англійським ключем.

## Застосунок для iOS та Android

Застосунок збирається з того самого коду, що й сайт, плюс нативний шар у папці `app/`. Сайт від цього не змінюється: `node build.js` (як і раніше) збирає тільки сайт.

```
app/
  src/main.js         точка входу нативного шару
  src/platform.js     сховище, вібрація, «Поділитися», нагадування, біометрія, віджет
  src/ui.js           «Сьогодні», щоденник, підготовка до сесії, перевірка місяця, налаштування, блокування, свайпи
  src/pdf.js          PDF для терапевта (завантажується лише на вимогу)
  src/strings.js      тексти застосунку UA/EN
  src/app.css         стилі нових екранів
  pdf-fonts/          шрифти для PDF (кирилиця + латиниця)
  assets/             джерела іконки й заставки
  android/, ios/      нативні проєкти Capacitor
```

Ядро (`src/app.js`) має кілька точок розширення (`H.*`). На сайті вони порожні, а в застосунку їх заповнює `app/src/ui.js`.

Збірка локально: `cd app && npm install && node ../build.js app && npx cap sync`. Далі Android Studio або Xcode.

Автозбірка: `.github/workflows/app.yml`. Після кожної зміни тестовий Android APK з'являється в Releases (тег `android-test`). iOS збирається для симулятора, а знімок екрана потрапляє в гілку `ci-ios`.
