# Нитка

Веб-застосунок для пошуку особистих цінностей: 192 цінності українською та англійською, сортування «Моє / Можливо / Ні», картки з поясненнями, нотатки, топ-12 → топ-5 і підсумок для терапевта. Усі дані зберігаються тільки в браузері користувача.

## Структура

```
src/
  index.html                      шаблон сторінки: розмітка і стилі
  app.js                          інтерфейс і логіка
  sw.js                           офлайн-режим (версію підставляє build.js)
  content/
    uk-values.js                  166 цінностей українською, згруповані за темами
    uk-values-red.js              ще 26 цінностей
    uk-shadow-and-steps.js        «коли її забагато» і «маленький крок»
    en-1.js, en-2.js, en-3.js     англійські тексти
public/                           шрифти, іконки, manifest — копіюються як є
build.js                          збирає все в dist/
```

## Збірка

```
node build.js
```

Результат з'являється в `dist/`. Зовнішніх залежностей немає.

## Публікація (Cloudflare Pages)

Налаштування проєкту:

- Framework preset: немає
- Build command: `node build.js`
- Build output directory: `dist`

Кожен push у гілку `main` автоматично публікує нову версію.

## Як змінити текст цінності

Українські тексти лежать у `src/content/uk-values.js` і `uk-values-red.js` (поля: `m` — що це, `l` — у житті, `q` — питання, `d` — не плутати, `t` — точніший переклад). «Коли її забагато» і «маленький крок» лежать у `uk-shadow-and-steps.js`. Англійські відповідники знаходяться в `en-*.js` під тим самим англійським ключем.
