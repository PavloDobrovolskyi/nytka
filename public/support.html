Підтримка

Питання, ідеї чи помилка? Пишіть на nytka.ua@gmail.com. Ми відповідаємо українською та англійською.

Де зберігаються мої записи?

Тільки на вашому пристрої. Ми їх не бачимо й не можемо відновити. Детальніше в політиці конфіденційності.

Як перенести дані на інший пристрій?

На сайті. Відкрийте «Мої → Резервна копія» і натисніть «Згенерувати код», а потім «Скопіювати код». Збережіть код у нотатках або надішліть його собі в месенджер. На іншому пристрої відкрийте той самий розділ, вставте код у поле «Встав сюди код з іншого пристрою» і натисніть «Відновити з коду».

У застосунку. На старому телефоні: «Мої → Резервна копія → Зберегти файл». Збережіть файл, наприклад, у «Файли» чи на хмарний диск. На новому телефоні: «Мої → Резервна копія → Відновити з файлу».

Відновлення замінює всі позначки на цьому пристрої даними з коду чи файлу.

Пишуть «Код не розпізнано»

Найчастіше код скопійовано не повністю. Він має починатися з NYTKA і йти до останнього символу без пропусків. Найнадійніше копіювати його кнопкою «Скопіювати код» і пересилати одним повідомленням.

Мої позначки зникли

Сайт зберігає дані окремо в кожному браузері. Якщо ви відкрили «Нитку» в іншому браузері чи на іншому пристрої, ваші позначки лишилися там, де ви їх робили. Перенесіть їх кодом, як описано вище. Дані також зникають, якщо очистити історію та дані сайтів у браузері, тому час від часу зберігайте код.

Я забув PIN (застосунок)

Якщо увімкнено Face ID чи відбиток, увійдіть через них і змініть PIN у налаштуваннях. Якщо ні, PIN можна скинути тільки разом з усіма даними. Тому радимо час від часу робити резервну копію.

Нагадування не приходять (застосунок)

Перевірте, що сповіщення для «Нитки» дозволені в налаштуваннях телефона і що режим «Не турбувати» не блокує їх.

Чи замінює «Нитка» терапію?

Ні. Це інструмент для самопізнання і помічник у роботі з психотерапевтом. У кризовій ситуації телефонуйте 112.

Support

Questions, ideas or a bug? Write to nytka.ua@gmail.com. We reply in Ukrainian and English.

Where are my entries stored?

Only on your device. We can't see or recover them. See the privacy policy for details.

How do I move my data to another device?

On the website. Open “Mine → Backup”, tap “Generate code” and then “Copy code”. Keep the code in your notes or send it to yourself in a messenger. On the other device, open the same section, paste the code into the “Paste the code from your other device here” field and tap “Restore from code”.

In the app. On the old phone: “Mine → Backup → Save file”. Save the file to Files or a cloud drive. On the new phone: “Mine → Backup → Restore from file”.

Restoring replaces all marks on this device with the data from the code or file.

It says “Code not recognised”

Usually the code wasn't copied in full. It should start with NYTKA and run to the very last character with nothing missing. The most reliable way is to copy it with the “Copy code” button and send it as a single message.

My marks have disappeared

The website keeps data separately in each browser. If you opened Nytka in a different browser or on a different device, your marks are still where you made them. Move them with a code as described above. Data is also lost if you clear your browser's history and site data, so save a code from time to time.

I forgot my PIN (app)

If Face ID or fingerprint is on, unlock with it and change the PIN in settings. Otherwise the PIN can only be reset together with all data, so we recommend making a backup from time to time.

Reminders don't arrive (app)

Check that notifications for Nytka are allowed in your phone's settings and that Do Not Disturb isn't blocking them.

Does Nytka replace therapy?

No. It's a self-discovery tool and a companion for your work with a psychotherapist. In a crisis, call your local emergency number (112 in Ukraine and the EU).
